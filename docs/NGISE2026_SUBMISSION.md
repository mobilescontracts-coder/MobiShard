# NGISE 2026 preparation checklist

Sources checked **11 October 2026**; no acceptance or eligibility decision implied.

## Conference requirements

The [CFP](https://ngise.org/call-for-papers) names Springer CCIS, double-blind
review, 6–8-page short and 15–17-page long camera-ready papers. It requires original
unpublished work not under review elsewhere. It encourages public code, models
and data and suggests a **Code and Data Policy** explaining access or restrictions.
The stated range is camera-ready; it does not separately state a review-stage
range or exclude references. This revision conservatively counts the whole PDF.

Both variants are **17 pages**, including title, abstract, declarations and
references, using the default class dimensions and body typography. Anonymous
and named versions are provided because the current submission stage is unknown.

## Before submission

- [ ] Confirm whether the manuscript is eligible as a new, invited, revised or
      camera-ready paper, and apply actual reviewer requests if relevant.
- [ ] Check originality, attribution, related-work overlap and venue eligibility.
      Rewriting or detector scores do not settle overlapping-publication issues.
- [ ] Verify names, affiliations, corresponding author and any optional ORCIDs.
- [ ] Replace **Disclosure of Interests** with a truthful statement approved by all
      authors. Add funding information only when verified.
- [ ] Review every scientific claim and the AI-assistance statement against the
      actual workflow; no independent human approval has been asserted for anyone.
- [ ] Finalize artifact licenses and public URL. The current Code and Data Policy
      honestly describes local availability and unresolved hosting.
- [ ] Rebuild after edits and inspect all pages. The build rejects totals outside
      15–17; extra declarations can change pagination.
- [ ] Use the anonymous PDF for blind paper review, not the identifiable repository
      or source archive. A blind artifact requires separate metadata/history work.
- [ ] Confirm extra-page charges, final-source deliverables, accessibility/alt-text
      requirements, publisher agreement and presentation obligations.
